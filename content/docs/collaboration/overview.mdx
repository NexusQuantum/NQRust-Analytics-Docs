---
title: Collaboration Overview
description: Work together in NQRust Analytics — multiple dashboards per user, sharing dashboards and chat threads with teammates, and starring favourites.
---

NQRust Analytics is multi-user. Each user signs in with an individual account,
and the collaboration features allow users to organize their own work and share
it with others in the same deployment.

Collaboration covers three capabilities:

- **Multiple dashboards per user** — each user can create and manage their own
  set of dashboards rather than being limited to a single shared one.
- **Sharing** — a dashboard owner can grant other users in the deployment access
  to a dashboard, and a thread (chat) owner can do the same for a conversation.
- **Starring** — each user can star (bookmark) the dashboards they use most so
  their favourites are easy to locate.

<Callout type="info">
These are **user-to-user shares within a single deployment**. You share with an
existing user by their email address — there are no public links or external
guests. The target email must belong to an account that already exists in the
system.
</Callout>
